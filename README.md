# MyChess ♟️

MyChess is an open-source chess game inspired by Chess.com. I started this project because I wanted to make my own chess game, with features I like and the freedom to customize how chess is played.

It's still a work in progress, but I'm constantly trying to improve it and add new features.

## Features

- Play against AI bots.
- Play with friends over LAN (same Wi-Fi network).
- Stockfish engine support.
- Custom chess pieces and movement rules.
- Different board themes.
- Player profiles and ratings.
- Move highlighting and premoves.
